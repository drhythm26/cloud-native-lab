# /learn 档案模板与字段

## 错题条目 → `docs/mistakes.md`

文件不存在时创建，文件头写一句：「本文件只收错题；实验复盘见各组件 note/。」条目按 `## NN` 递增编号：

    ## NN <路线大项>/<主题>：<题干一句话>
    - 日期：YYYY-MM-DD
    - 题目：<原题>
    - 我的答案：<原答案，或「弃答」>
    - 正确要点：<标准答案关键点，不必全文>
    - 错因：<一句话，写认知偏差，不写「粗心」>
    - 复测：未 ｜ YYYY-MM-DD 通过

复习模式中该题答对 → 「复测」改为通过日期。

## 复盘条目 → 组件 `note/`

沿用仓库现有「操作 / 现象 / 原因 / 结论」风格，`## NN` 续接目标文件当前最大编号：

    ## NN <主题>：<一句话结论式标题>

    操作：
    <改了哪个文件 / 敲了什么命令>

    现象：
    ```sh
    > <真实命令>
    <真实输出节选>
    ```

    原因：
    <机制解释，可用 A → B → C 箭头链>

    结论：
    - <可迁移的规律，来自用户口头复盘>

现象即原因时，原因段可并入结论（参照 apps/go-api/note/go-api.md 的 01、05 先例）。

## 学生画像 → 持久记忆（永续，总量控制在一屏内）

- 各路线大项评级：入门 / 熟练 / 扎实
- 易错模式：日期 + 一句话，滚动保留最近约 10 条
- 有效的提示方式（如「给数据流图比给定义有效」）
- 节奏偏好；「未亲手验证」标记（守则 1 触发时记）
